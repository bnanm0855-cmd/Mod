# مملكة الجيمر — حزمة ربط Supabase

هذه الحزمة أُضيفت في مستودع Mod داخل مجلد مستقل حتى لا تتغير الملفات الأخرى الموجودة في المستودع.

## محتويات الحزمة
- `supabase-config.example.js`: نموذج إعداد عنوان المشروع ومفتاح Publishable.
- `supabase-client.js`: وظائف المصادقة والتحقق من دور المدير، رفع الملفات، قراءة الألعاب المنشورة، والحذف.
- تعتمد على جدول `public.games` و`public.user_roles` والحاويات `game-files` و`game-thumbnails`.

## الإعداد
1. انسخ `supabase-config.example.js` إلى `supabase-config.js`.
2. ضع عنوان مشروع Supabase ومفتاح `sb_publishable_...` فقط.
3. لا تضع `service_role` أو كلمة مرور قاعدة البيانات في ملفات الواجهة.
4. قدّم الصفحات عبر خادم محلي أو استضافة HTTPS؛ وحدات JavaScript لا تعمل بصورة موثوقة عند فتح HTML مباشرة عبر file://.

## مطابقة أعمدة قاعدة البيانات
الجدول الموجود وفق الفحص السابق:
- `id` (uuid)
- `title`, `description`, `category`, `instructions`
- `html_file_path`, `thumbnail_path`, `status`, `created_at`

يجب أن تكون قيمة حالة النشر `published` حتى تظهر اللعبة للزوار، وفق سياسة القراءة الموجودة.

## ملاحظة مهمة عن الحالة الحالية
هذه ملفات طبقة التكامل، وليست إعلاناً بأن صفحتي المدير والزوار قد تم ربطهما نهائياً. ما زال يلزم توصيل أحداث النماذج والعرض في ملفات HTML الحالية بهذه الدوال، ثم اختبار تسجيل الدخول والرفع والتشغيل في متصفح فعلي. لم يتم تغيير `main` أو دمج أي شيء تلقائياً.
